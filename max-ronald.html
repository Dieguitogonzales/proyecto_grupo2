🔀 ¿Qué es Gitflow?

Gitflow es una estrategia de ramas en Git que permite organizar el desarrollo de software de manera estructurada. Define ramas principales como main y develop, y ramas auxiliares como feature/*, release/* y hotfix/*.

🌿 Ramas utilizadas en este proyecto

  • main: Rama principal, contiene la versión estable del proyecto.
  • develop: Rama de integración donde se fusionan las funcionalidades.
  • feature/max-ronald-vscode: Rama personal para agregar esta página.
  • feature/otros-integrantes: Ramas de los demás compañeros.

✅ Proceso realizado

  1. Clonamos el repositorio desde GitHub.
  2. Trajimos la rama develop actualizada.
  3. Creamos una rama feature/tu-nombre.
  4. Agregamos una página HTML con contenido relevante.
  5. Subimos la rama al repositorio remoto con git push.
  6. Crearemos un Pull Request para fusionar con develop.
